# Handoff

Hand the current work over to another session or runtime. Topic or destination, if given: "$ARGUMENTS".

Follow `system/rituals.md#handoff`. Write the handoff note under `_private/state/handoff/`, log one line that
points to it with `python3 tools/now.py log --private`, and append the five-line delta to the thread's dossier
if the thread has one.

Then give the path of the note in one line. Do not summarize the note in the conversation: the next session
reads the file.
