# Dossier

Run the return ritual for the "$ARGUMENTS" thread by reading its dossier.

List registered threads with `python3 tools/now.py threads`. The authority is the `threads` array in
`system/memory-config.json`; do not hard-code the list here.

After reading, summarize (1) the current position, (2) settled conclusions, and (3) open questions. If needed,
use recall to recover the original discussion, then begin. Before leaving the session, remember the closing
ritual: append a five-line delta.
