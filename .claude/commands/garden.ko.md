# 정원사

정원사 패스를 실행해줘: `tools/wf_gardener.js` 워크플로를 돌리고 (report-only),
산출된 state/gardener-*.md 리포트를 요약해서 판정할 항목을 제시해줘.
이 수동 도구는 제안만 한다 — 집행은 내 판정 후에 (system/design-memory-runtime.md#manual-garden).
선택적으로 설치하는 자율 개선 adapter의 실행 권한을 물려받지 않는다.
