# 사고렌즈 — 호출 인덱스 (핫셋)

**이 파일은 호출용 압축 인덱스다.** 적용의 깊이는 렌즈별 문서에 있다 — 켠 다음에는
반드시 그 파일을 연다.

> 구조 원리: 원장/핫셋 이원화. 렌즈 문서 = 원장(깊게, 자란다) · 이 README = 핫셋(한 줄, 호출용).
> **적용 후 30초 라벨링**: 쓴 렌즈 문서의 시금석에 한 줄 append (날짜 | 사례 | 결과).
> 라벨이 쌓이지 않는 렌즈는 퇴역 후보다 — 증거 기반으로 산다.

## 표준 시퀀스 (조합)

- **막힌 문제 재시동**: 장부(보존량) → 극한(다이얼) → 역산(반증)
- **증거·조언 수신**: 침묵(표본 선택) → 인센티브(발화자 보수) → 파인만(직접 재계산)
- **결정**: 에르고드(문 분류·파산 검사) → 한계효용(배분) → 역산(프리모템)
- **자기 단언 감지**: 거울 단독 게이트 — 통과 후에만 다른 렌즈 진행
- **시스템 개입 설계**: 되먹임(루프·지연) → 울타리(기존 구조의 지대) → 장부(비용 회계)
- **novelty 스트레스 테스트**: 구조 대응 풀 프로토콜 (P0→P4)

## 운영 규칙

- **상한 13.** 추가는 퇴역과 교환으로만. 근거는 시금석(=사용 실적).
- **매 질문마다 렌즈를 돌리지 않는다.** 호출 조건: 막힌 문제 · 설계 · 결정 · 명시적 요청.
  가벼운 질문에 렌즈 라벨을 붙이는 것 자체가 실패 지형(체크리스트 순회)이다.
- **검토 후 주차된 후보** (재제안 금지, 부활 조건 명시):
  - *스케일/상전이* → 극한 렌즈에 조항으로 흡수 (부활 조건: 상전이 탐지가 극한 호출과
    분리되어 불리는 사례 3회)
  - *시간/옵션성* → 에르고드(비대칭 베팅)와 한계효용(다음 시간)에 분산 수용
  - *미학/취향* → 미성숙 주차 (부활 조건: "취향 = 미래 합의 예측" 프레임이 실전 결정을
    바꾼 사례 등장)
- 정본은 이 디렉토리다. 다른 곳의 요약과 충돌하면 여기가 이긴다.
