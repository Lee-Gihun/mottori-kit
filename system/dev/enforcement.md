# Rules and where they are enforced

One row per rule of the kit: what it says, where it is enforced, one test that exercises it, and how far the
enforcement goes. A rule a kit document states that has no row here is checked by nothing.
`tools/tests/test_rules_table.py` checks that every cited test function exists and every status is one of the
four below; `tools/dev/evidencecheck.py` checks the `test:` markers the same way.

Status: **ENFORCED**: a tool, hook or doctor check stops the failure at its boundary, and the cited test shows
it. **DETECTED**: a machine finds the violation but does not always stop it, or finds it only when it is run.
**REVIEW**: only a person's judgement or care closes it. **UNENFORCED**: nothing finds or stops it.

A row that is not ENFORCED says in its last column what can still go wrong.
